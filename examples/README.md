# Examples

Everything under `examples/` is example-only and intentionally outside the live v1 quickstart.

The canonical local-first path still starts with the root quickstart and scripts under `scripts/`.
Use the directories here to study extension patterns without changing the live MVP flow.

## Available example-only paths

- [`gitops/`](gitops/README.md) — placeholder for a lightweight GitOps compatibility example
- [`helm/`](helm/README.md) — placeholder for optional Helm packaging guidance
- [`observability/`](observability/README.md) — placeholder for a small observability starter
- [`provider-sample/`](provider-sample/README.md) — neutral scaffold for future provider-oriented examples

## Boundary reminder

- Keep provider-oriented material under `examples/` and `docs/examples/`
- Do not wire example-only assets into the canonical bootstrap/validate/demo flow
- Treat the provider sample as a learning scaffold, not official provider support
