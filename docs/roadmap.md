# Roadmap

## V1 live MVP

The live MVP is intentionally small and trustworthy:
- one canonical local path
- Terraform demo foundation
- Kubernetes demo workload
- validation and CI scaffolding
- AI-friendly contributor guidance

## Example-only v1 material

These can exist as examples without becoming part of the happy path:
- provider-oriented sample structure
- Helm sample
- observability sample
- GitOps sample
- extra demo workload variants

## Later phases

Potential future work after the canonical path is stable:
- second-path cloud provider quickstart
- stronger observability story
- secrets-management starter integrations
- richer policy/security examples
- service mesh or operator-based platform experiments
- deeper production-readiness packs
