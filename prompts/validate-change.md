# Prompt: Validate a proposed change

Review a proposed change against these questions:
1. Does it preserve the canonical path?
2. Does it keep live MVP and example-only assets clearly separated?
3. Does it keep Terraform's role minimal but real?
4. Does it update docs and validation expectations when needed?
5. Does it make the one-hour clone-to-demo story harder?

If the answer to #5 is yes, recommend moving the change out of the live MVP path.
